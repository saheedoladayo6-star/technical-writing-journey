# How to Install Node.js on Windows
## Overview
This guides explains how to install Node.js on a Windows computer.
## Prerequisites 
- A Windows computer
- An internet connection
- Administrator privileges
## Steps
### 1. Visit the Node.js website
Open your browser and go to: https://nodejs.org
### 2. Download Node.js
Click the **LTS** version to download the installer.
### 3. Run the installer
Double-click the downloaded file.
### 4. Accept the license
Read the license agreement and click **Next**.
### Complete the installation 
Keep the default settings and click **Install**.
### 5. Verify the installation 
Open Command Prompt and run:
```bash
node -v
```
You should see the installed Node.js version.
## Conclusion 
Node.js is now installed and ready to use.

## Troubleshooting
If the `node -v` command is not recognized:
- Restart your computer.
- Reopen Command Prompt.
- Reinstall Node.js if necessary.
